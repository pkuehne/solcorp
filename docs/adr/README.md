# Architecture Decision Records

ADRs capture significant design decisions: the context, the decision made, alternatives considered, and consequences accepted. They record the "why" that isn't visible in the code.

## Format

File naming: `NNN-short-title.md` (e.g. `001-ecs-with-flecs.md`)

Minimum required sections: **Context**, **Decision**, **Consequences**
