# Windows

This section documents the major UI windows in Solcorp. All windows are opened from the [Main Toolbar](gameplay/windows/main-toolbar.md).

## Rockets

| Window | Description |
|--------|-------------|
| [Rocket List](gameplay/windows/rocket-list.md) | Browse and filter all rockets your company owns |
| [Rocket Detail](gameplay/windows/rocket-detail.md) | View a rocket's stats, lift capacities, and current plan |

## Contracts

| Window | Description |
|--------|-------------|
| [Contract List](gameplay/windows/contract-list.md) | Browse and filter available and active contracts |
| [Contract Detail](gameplay/windows/contract-detail.md) | Review a contract's terms and accept or reject it |

## Launches

| Window | Description |
|--------|-------------|
| [Active Launches](gameplay/windows/active-launches.md) | Monitor the status and progress of all scheduled launches |
| [Launch Plan](gameplay/windows/launch-plan.md) | Create or view a launch plan, configure rocket, launchpad, orbit, and payloads |
